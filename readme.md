_Висновки щодо ефективності алгоритмів пошуку підрядків_
Було порівняно три алгоритми: Boyer–Moore, Knuth–Morris–Pratt (KMP) та Rabin–Karp на двох текстах і двох типах патернів (існуючий / вигаданий).

_Результати:_

- Boyer–Moore стабільно найшвидший у всіх сценаріях
  (~0.0005–0.0010 сек).
  Це пов’язано з тим, що він виконує порівняння справа наліво
  та пропускає великі частини тексту завдяки таблиці зсувів.

- KMP демонструє середню швидкість
  (~0.0016–0.0024 сек), оскільки працює послідовно без можливості великих стрибків.

- Rabin–Karp найповільніший
  (~0.0047–0.0071 сек), через обчислення хешів і модульної арифметики.

_Висновок_:
Алгоритм Boyer–Moore є найефективнішим для пошуку підрядків у великих текстах природної мови.
KMP показує стабільний, але не найкращий результат.
Rabin–Karp програє в однопатерновому пошуку, але корисний при множинних шаблонах.
